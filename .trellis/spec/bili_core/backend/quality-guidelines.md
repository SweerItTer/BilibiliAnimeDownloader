# Core quality and behavior contracts

## 1. Scope / trigger

These rules apply to the typed service cutover and all consumer-visible selection, durability and native media changes. Correctness/data retention precede convenience; no stub or best-effort success can satisfy a requested component.

## 2. Signatures

`QualityCatalog::select(&DownloadSelection) -> Result<(RepresentationKey, Option<RepresentationKey>)>` is the reusable selection operation used by core planning. `Core::{plan,enqueue,control,merge,shutdown}` own lifecycle transitions. Queue snapshots share immutable `Arc<JobSnapshot>` values and immutable plan Arcs; progress changes rebuild only the affected job snapshot.

`CoreConfig.timeout` is the API client's total request budget and the anonymous media client's connect/read-idle budget, not a maximum video duration.

## 3. Contracts

- Explicit filters constrain candidates first. Default to highest actual obtainable spatial resolution; numeric qn/server labels are not a universal resolution ranking. FPS/HDR/codec are separate; unknown dimensions stay unknown. Do not claim HDR universally outranks SDR.
- Numeric DASH IDs may repeat across codec variants. An explicit ID must resolve uniquely with available selectors or fail, never choose the first silently. Persist and renew the entire representation key.
- Search challenge-only payloads, empty successful pages, malformed schemas and access failures differ. Covers are posters, not videoshot sprites.
- Playback payload traversal follows only object-valued `raw`/`data`/`result` envelopes. A scalar `result: "suee"` is an ordinary UGC status label, not a nested playback object. Recognize playback fields by their expected types (`video_info`/`dash` objects and `durl`/`support_formats` arrays); do not let a status label hide real representations or classify a parser failure as upstream unavailability.
- Preview/trial classification comes from explicit upstream access/preview fields, not empty representations or a quality number. A playable restricted trial remains preview-only and cannot satisfy a full film/episode plan; an actual trailer episode must have its own explicit upstream identity. Preserve available source duration/identity distinctions and do not invent a preview opt-in or blanket membership/region diagnosis.
- One host-owned Tokio runtime remains alive through awaited shutdown. No signal handler, process exit, nested runtime, orphan native worker or detached queue task belongs in core.
- Commands/events/history are bounded. Progress is coalesced to at most five updates per second per active resource/job. Dirty metadata persistence does not rewrite unchanged completed history. Large-file hashing uses tracked cancellation-aware workers/async I/O, not the reducer or synchronous constructor.
- Failed durable admission/transition fail-stops the writer session and cancels owned work; repairing the disk does not silently admit previously unacknowledged jobs. Recovery starts a new writer from the last atomic index capture.
- Media retrieval uses an anonymous dedicated client; no Cookie/auth is sent to CDN. Redirect policy is explicit and each target is checked. Resume uses identity encoding, a strong validator and exact Content-Range continuity, not matching IDs alone.
- For each selected DASH representation or direct segment, try the primary URL before its API-provided backups; choose the first URL passing the existing HTTPS, CDN host, default-port and no-userinfo/password policy. Keep selection and representation identity unchanged, and retain same-origin checks for explicit redirects.
- API, anonymous media, cover and explicit sidecar requests share `api::USER_AGENT`; sidecars import it instead of overriding it with a module-local identity. Use the fixed Chrome-compatible value established by the recorded same-URI `403 → 200/BMFF → 403` UA control. This is observed compatibility for the tested public request, not a universal server-required value. Do not add UA rotation, a runtime knob, or credential/proxy/fingerprint changes. Preserve the existing Referer and Range/If-Range rules; validate behavior through the real CLI path, not a permanent string-pinning or wiring test.
- The dedicated API client retains `.timeout(config.timeout)`. The anonymous media client uses `.connect_timeout(config.timeout).read_timeout(config.timeout)` without a total body deadline. Continuous successful reads may outlast that duration; stalled reads must still time out. Do not compensate by increasing retry counts or the configured duration, and do not weaken checkpoint/strong-validator rules.
- Production remux uses shared FFmpeg libraries on local files only, packet copy, no programs/encoders/player/transcoding. DASH retains both chosen audio/video; sequential inputs map onto the same compatible streams with ordered timestamps, not parallel output tracks per segment. Verify kinds/codecs/dimensions/timeline/metadata before promotion.
- Selected-plan native verification is media-type specific: codec applies to every stream; dimensions/FPS/color/HDR constrain video; sample rate/channels/language constrain audio. Upstream audio keys can contain video-only placeholder dimensions even though native audio has no dimensions. Keep the complete persisted/refreshed key unchanged for representation identity; do not turn irrelevant fields into native audio requirements, normalize stored keys, or widen FPS tolerances to repair a subtype mismatch.
- Resolve native API changes against the installed source-built headers/bindings, not similarly named compiler suggestions. FFmpeg 8 coded stream side data belongs to codec parameters; use their actual deep-copy ownership path and preserve HDR/display metadata. Never cast an `AVStream` to an `AVFrame` or drop preservation to compile. Enumerate real demux/mux capabilities through supported APIs; report the loaded FFmpeg release separately from per-library ABI versions.
- Resolve Windows ACL bindings against pinned `windows-sys` definitions: security-information/inheritance constants live in `Win32::Security`, `OpenProcessToken` in `System::Threading`, `LocalFree` in `Foundation`, and trustee kinds use `Authorization::TRUSTEE_TYPE`. Preserve current-user/SYSTEM access, protected DACL, inheritance policy and failure behavior; pointer conversion for `LocalFree` must match its `HLOCAL` type. Unix-only `OpenOptions` mutation retains0600/O_NOFOLLOW without Windows unused-mut suppression. Host checks do not compile Windows cfg; require native Windows CI and real private-ACL runtime proof.
- Native source/prefix directories and Cargo cache cleanup have separate ownership: scope Rust cache workspaces to `target/TRIPLE`, with a scope-version prefix preventing restoration of old whole-`target` caches. Never allow Cargo cache pruning to touch `target/native` or native build trees. Materialize all members of the checksum-verified native archive with the existing safe extraction filter on each build; a surviving source directory/configure file is not completeness proof. Do not delete unknown files or change profile/toolchain/ABI to repair cache damage.
- Pinned FFmpeg MSVC shared installation places genuine same-name import `.lib` files in `bin`, while existing bindings/SDK consumers search `lib`. The recipe copies exactly `avformat.lib`, `avcodec.lib` and `avutil.lib` byte-for-byte into `lib`, preserves DLLs in `bin`, records both hashes and fails on missing/corrupted copies. Never synthesize aliases/static libraries or alter link consumers to mask this layout mismatch; actual MSVC linkage and extracted PE/DLL closure qualify shared-library integration.
- Windows `File::sync_all` requires a write-capable handle (`FlushFileBuffers`/`GENERIC_WRITE`). Promotion opens only its existing source with read access plus Windows-only write access, without create/truncate, then retains flush → atomic no-clobber hard link → directory sync ordering. Unix stays read-only; flush errors must propagate rather than being ignored or converted to conflicts.
- FFmpeg concat manifest single quotes preserve backslashes literally; apostrophes require closing the quote, writing an escaped apostrophe outside it, then reopening. Stream borrowed path chunks directly into the existing manifest without an escaped-string allocation. Preserve canonical Windows verbatim/UNC paths and local-file protocol restrictions; qualify via real ordered corpus remux using space/apostrophe names and a distinct Unix literal-backslash input, not merely manifest-text assertions.
- Dialogue and danmaku are separate independently usable sidecars. Use the current first-party subtitle protobuf descriptor and `oid/pid/type=1` adapter; a valid empty subtitle reply under `All` succeeds, while missing explicit selections and access/protocol failures remain visible. Legacy JSON is a separate adapter, not catch-all proof that modern discovery worked.
- Current-pool danmaku view has `text_side` tag 3 and `dm_sge` tag 4; `total` is segment count and `page_size` is milliseconds. Fetch every advertised segment, bound aggregate pool memory and honor cancellation during HTTP/body waits. Preserve valid advanced/unsupported modes in JSONL/XML; count only ASS-specific omissions. Mode 4 is bottom and mode 5 is top. Primary wire/source evidence is recorded in the task's `research/danmaku-primary-wire.md` and `research/subtitle-primary-wire.md`.
- ASS presentation must preserve visible literal backslashes/braces and actual newlines without permitting comment text to inject overrides. libass does not decode `\\` as one literal slash; a zero-width separator after a literal slash disarms `\N`, `\n`, `\h` and brace escapes while generated movement tags remain active. Follow the [libass maintainer's parsing guidance](https://github.com/libass/libass/issues/194#issuecomment-139557663), not C-style string escaping. JSONL/XML retain their independent raw-text contracts. Permanent tests assert consumer-interpreted text and override boundaries, not an incidental encoded substring; focused actual-libass rendering must prove the unsafe-input edge separately from ordinary-text playback.

## 4. Validation / error matrix

Ambiguous or unavailable exact selection fails visibly. A changed URL can still be the same representation but must pass validator continuity; a changed complete key requires attention. Stop before commit returns paused/cancelled only after joins/checkpoint. Stop during Committing waits for the actual promoted/failed result. Sidecar failure is nonzero at the shell while verified video remains reusable.

## 5. Good / base / bad

Good: lower-qn actual 4K beats high-qn Dolby 1080p by default; user HDR filter can choose a different result explicitly. Base: no-auto-merge stops at Downloaded with owned inputs retained. Bad: silent fallback, size-only skip, output overwrite, parallel legacy-segment tracks, or a converter claiming deleted/historical danmaku completeness.

## 6. Tests required

Behavior tests cover resolution versus qn, repeated IDs/codec qualification, challenge/empty/schema boundaries, real HTTP range/cancel/checkpoint faults, state-writer crash/index half-commit/fail-stop, original retention, real native corpus packet/timeline properties, and sidecar protobuf/escaping/lanes. No forwarding/source-text/default-word tests. Synthetic auth tests must isolate OS store backends/namespaces and never touch the user's production keyring. Windows private ACL behavior requires real Windows CI evidence. Delivery alone runs consolidated fmt/check/clippy/test/SDK/package/live smoke; tests listed in specs are not passing evidence.

`cargo test -p bili_core --lib service::media_client_timeout_tests --locked -- --nocapture` exercises the actual media-client factory on loopback: a frequently progressing body must arrive completely even when its total duration exceeds the configured budget, while a stalled body must report `is_timeout()`. Use generous scheduling margins, bounded server cleanup before assertions and no exact elapsed-time pins.

Transfer error regression must retain the short-body zero-offset/zero-tail assertions and exercise a successful same-path acquisition after the error returns. Check final bytes, durable offset and SHA-256; stress real loopback I/O without timing sleeps. Transport failure returns must join buffered file writes before relinquishing ownership, not add truncation or retry delays.

`cargo test --locked -p bili_core --lib representation_validation_tests -- --nocapture` exercises mixed-stream selected-plan verification, including video-only dimensions and audio codec/sample-rate/channel rejection. Keep this a behavioral call through `validate_plan`, not a source/default pin or a permanent environment-gated diagnostic route.

## 7. Wrong versus correct

Wrong: select largest numeric qn, then renew by `id` alone. Correct: filter complete obtainable representations, select by actual spatial resolution with qualified ties, reject ambiguous IDs, persist the full key, and require an exact refreshed match.
