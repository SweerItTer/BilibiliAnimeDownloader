# Security Policy

## Scope

This policy covers security issues in this repository's current Rust source and officially published Linux x86_64 CLI Alpha packages. See [README.md](README.md) and the [release list](https://github.com/SweerItTer/BilibiliAnimeDownloader/releases) for current release status. The repository also documents a Windows source build, but no Windows CLI package has been published; macOS is out of scope. Older releases contain the former Python application. No support window or security-fix commitment is stated for those releases or for unpublished builds.

Official packages may include FFmpeg shared libraries and other third-party components with separate terms and notices. If a report concerns a bundled component, include its name and version as shown in the package notices. This policy does not promise that a third-party maintainer will provide a fix.

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/SweerItTer/BilibiliAnimeDownloader/security/advisories/new) to report a suspected security vulnerability. This form sends the report privately to the repository maintainers.

Include the affected release or source revision, platform, impact, and steps to reproduce when known. Do not include cookies, session tokens, passwords, or other credentials. Do not publish vulnerability details in an issue, pull request, discussion, or other public channel before maintainers have had an opportunity to assess the report privately.

This channel is for security vulnerabilities only. For non-security conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Response

No response deadline or remediation guarantee is stated. Maintainers may use GitHub Security Advisories to coordinate a fix and disclosure when appropriate.
